# Store asset sources

`icon.svg` is the original application mark. Capture the file list from the current app using sample files. Save it as `screenshots/01-files.png` in this directory, then run `feature.py` to generate the feature SVG and its 1024 × 500 PNG. The renderer requires `rsvg-convert`.

NASA sample-image notices are in [Third-party notices](../../THIRD_PARTY_NOTICES.md).
