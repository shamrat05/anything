# Anything privacy policy

Updated 21 November 2026.

Anything is an Android app provided by CallCraft Studio. Contact [shamrat@callcraftstudio.com](mailto:shamrat@callcraftstudio.com). Website: [callcraftstudio.com](https://callcraftstudio.com/).

## Data on your device

The app stores a local index containing file names, paths, file or folder type, size and modified time. Searches read that index. Previews read only the file you open or the visible thumbnails. The index is not a copy of your file contents.

The app can search launchable apps and, with your permission, contact names and phone numbers. Contact search results stay in memory and are not added to the file index. A recent app list can remain in memory for up to 30 seconds.

Recent and saved search terms, display settings and a temporary file selection are stored in the app's private storage. Recent and saved searches each retain up to 50 entries. The file clipboard expires after 24 hours. Read-access records for opened or shared files expire after seven days. Search terms can contain personal information if you enter it.

## Permissions

All-files access lets the app index accessible storage, show previews and copy, move or delete files you select. You can decline it and still search apps. Contacts access is requested when you choose to enable contact search. Notification access is optional and lets the app show indexing progress and a Stop action. Root access is optional and uses your installed root manager.

The Google Play version does not request SMS access or provide SMS search. The separately distributed full APK can request SMS access when you enable that feature. Its sender and message results stay in memory and are not added to the file index.

## Collection and sharing

The app has no internet permission, account, advertising, analytics or crash-reporting service. CallCraft Studio does not receive file metadata, file contents, contacts, messages, installed-app details or search terms from the app.

If you choose an external app to open or share a file, that app receives read access to the selected file. Its handling of that file is governed by its own policy. Android and your root manager can retain their own system records.

## Your controls

Revoke permissions in Android Settings. Clear recent or saved searches from their menus. Clear the app's storage or uninstall it to remove its local index, search history and settings. Files that you copied or moved remain in their destination folders. Deleting a file asks for confirmation and permanently removes it from storage. The app excludes its data from Android cloud backup and device transfer.

## Support and changes

Emailing support sends the information you include through your email provider and our email service. Do not include private file contents or contact/message details unless needed for your request. We use support correspondence to answer you and resolve the issue.

The Help screen can include optional diagnostics in a report you choose to send. These include version information, counts, recent Anything events held in memory, and app exit reasons where Android provides them. Anything does not collect system logs, file paths, searches, contacts or messages for diagnostics. You can review the report before opening an email draft or copying it to the CallCraft Studio contact form. Nothing is uploaded by the app.

This notice will be updated when the app's data handling changes. The current policy is published at [callcraftstudio.com/anything/privacy/](https://callcraftstudio.com/anything/privacy/).
