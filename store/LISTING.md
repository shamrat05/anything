## Full description

Find files and folders by name. Keep a local index and filter results by type, path, size or modified date.

Choose a list, compact list or photo grid. Touch the right edge to drag through results. A slim bar shows the current date, size range or letter. Filter a category by its available file formats. Show or hide dot files and hidden folders. Search inside folders and return through browsed directories with Back or the search-field X.

Preview images, video, audio, PDF, text and ZIP files. Swipe between files. Tap file icons to select, then copy, move or delete the selection. Existing destination names are preserved. Moves stay within the same filesystem. Deletion asks for confirmation.

Search apps and contacts from the same search field. Contacts access is optional. All-files access is used to build the file index, display previews and perform file actions. Root folders require an already rooted device and a root grant.

The app processes searches on your device. No account, advertising or analytics.
